# jpFun 语法规范

## 1. 核心思想
完全函数式，但提供语法糖供快捷调用。

## 2. 基本类型
- 字符串，用引号包裹，只能用英文双引号`"`。如果不会引起歧义，可以不加引号。（单引号用于其他语法糖）
    - 引号必须配对才算字符串，找不到闭引号时它只是普通字符；可跨行
    - `\` 后的任意字符取字面量，如 `"说\"你好\""`；没有 `\n` 这类语义转义
- bool值，只能为 `true` / `false`，
- 数字
- 内容，用 `{}` 包裹。如果不会引起歧义，可以不加括号
- 标签
- 长度，表现为 `${数字}${单位}` 的字符串。单位仅支持 `px`(默认) `em`，会统一固化到 `px`

“内容”的基本元素：
- 函数调用：`@func(...)`，函数名后必须立即接`(`，参数使用逗号分隔，参数可以是(2)中提到的四个类型
- 标签：`XXX@label`，不按要求的函数调用都会被理解为label，用于关系型函数的参数
    - 绑定到它前面最近的可标注对象；`@div` `@box` `@text` 这类对标签透明，会被跳过继续向前找
    - 目标已经有标签，或前面是不可标注的复合体（如宙主无可标注内容的 `@grace`）时，标签失效并报警告

> 歧义：比如字符串为 `"123,456"`，在函数调用时，逗号是参数的分隔符，如果没有引号，则会认为传递了两个数字，引发歧义。因此必须用引号分割

注释：`%` 直到行末

## 3. 主要函数
- `@1(tonality)` 修改调性 如 `1=C` 作用域为当前时间之后
    - 规范写法：`[音名][最多一个 #/b][绝对八度]`，音名可用 `A`~`G` 或 `1`~`7`，八度可省（默认 4）
    - 不规范但读得懂的写法会**按实际音高归一化**，并报 `W_KEY_TONALITY` 说明切换到了什么：`C##`→`D4`、`Cbb`→`Bb3`、`B#4`→`C5`、`Cn`→`C4`、小写 `f#`→`F#4`；落在黑键上时跟随原来的升降方向拼写
    - 彻底读不懂时（`X`、`H4`）退回 `C4`，同样报 `W_KEY_TONALITY`
    - `strict` 为真时，以上两种情况都抛 `E_KEY_TONALITY`
- `@tempo(number)` 修改bpm 作用域为当前时间之后
- `@program(number)` 将当前音轨后续音符切换到 MIDI program `0..127`，默认值为 `0`
- `@meter(num, den, size=0.7em)` 设置拍号 `num/den`，以分数形式显示
    - 第一条小节线前允许不满拍，但不能超拍；之后由小节线、拍号变更或文档结尾关闭并校验完整时长
- `@set(key=value, ...)` 修改函数的缺省值，作用域为当前 `{}`
    - 写法 `函数名.参数名=值`，按该参数声明的类型解析；函数名可写别名
    - 找不到对应的函数或参数会报警并忽略，不会静默无效
    几个系统变量（不属于任何函数，直接写名字）:
    - `fontsize`: length类型，是所有`em`的基准
    - `strict`: bool类型，开启后如果函数未定义不再忽略，一些宽容的语法糖也将被禁止

- `@page(width, height, top, bottom, left, right, gap, numbering)` 设置文档页面
    - 只能在文档顶层声明一次；嵌套声明或后续重复声明会产生诊断并被忽略
    - 所有参数都是长度，parse 时按当时的 `em` 固化为 px
    - 默认：`width=794px`、`height=0px`（无限高）、上下边距 `48px`、左右边距 `40px`、`gap=1em`
    - `height <= 0` 表示无限高，不会换页
    - 有限高度下，如果一行连同上下边距都放不下，layout 直接报错
    - 一页放不下下一行时从下一页开始；已封口页面的行间距会平分剩余纵向空间，末页保持最小 `gap`

- `@head(left={}, center={}, right={})` 排版曲谱头
    - 可在内容作用域中嵌套，也可与前后内容共享逻辑谱面行；需要换行时显式写 `@br()`
        - 三槽第一层节点各占一行：`left={A B}` 是两行，`left={{A B}}` 是同行
        - 内部内容必须全部为零时长；普通函数、stack/voices 和 attachment 仍走全局 Track、列与关系布局
        - left/right 整体底部对齐；较高侧的顶部贴住 center 第一行的下侧
        - left 每行从左向右、right 每行从右向左紧凑排列顶层单元，单元间隔为 `0.25em`；复合内容整体移动
        - 行声明语法糖：
            ```
            H.title: 小星星
            H.subtitle: 经典儿歌
            H.author: 佚名 作词
            H.author: 莫扎特 作曲
            H.signature: 1=C 4/4
            H.tempo: 94
            ```
        - 连续声明合成一个 head，空行或普通内容结束组合；一次声明固定为一行
        - `H.left/center/right:` 接受任意零时长 DSL 内容；裸文本自动转成 `@text`

- `@stack(...)` 临时伴奏/临时多声部：第一个成员留在宿主轨，其余成员按书写顺序依次向上叠放；与 `^` 的区别见下面的对照表
- `@voices(...)` 多声部块：所有成员都有独立轨道，整块在宿主基线上局部居中（首末两条基线的中点对齐宿主轴），两个以上成员时在声部名与音符之间画多声部括线；里面只能是 `@voice`，一般用语法糖创建
- `@voice({}, 音轨名, 名称1={}, 名称2={}, ...)`
    语法糖:
    ```
    N(音轨名): ... (note等元素)
    L(名称1): ... 歌词1
    L(名称2): ... 歌词2
    ```
    起始条件1: `N(xxx):`。终止条件：该层级的换行符或结束。可以有大括号，大括号内随意换行
    起始条件2: `L(xxx):`。终止条件：该层级的换行符或结束。如果上一个不是voice就报错
    - 歌词默认按空格、连字符和非 ASCII 字符分词；`{你好}` 强制把多字符文本作为一个音符槽，显示时不含花括号

- `@up(...)` 和弦：把同一时间位置的几个音合成一个符号。语法糖 `^`，自下而上写
    - 时值、对齐基准和减时线都以最下面的成员为准
    - up 中至少有一个可标注成员时，up 整体才能被标注
    - `{1@x}^{@1(C4)}` 中 `x` 标注成员 `1`，`@tie(x,y)` 从 `1` 起跳
    - `{1^@1(C4)}@x` 中 `x` 标注整个 up，`@tie(x,y)` 从最上面的成员起跳
    - 每个参数必须恰好产生一个可见对象，放不下整段旋律

- `@down(...)` 向下堆叠：第一个参数是宿主，其余依次叠在它下方。语法糖 `_`
    - 常用于力度记号等写在音符下面的标记：`1 _ $p`
    - 与 `^` 共用同一个容器，混写时**全部绑到同一个宿主**，和 LaTeX 的上下标一样，不需要括号分组
        - `1^2_3^4_5` 等价于 `@down(@up(1, 2, 4), 3, 5)`：`1` 是宿主，`2 4` 在上，`3 5` 在下
    - 宿主留在轨道基线上，两侧成员各自向外撑开行高；横向宽度仍只取宿主
    - 播放事件按**先附属成员、最后宿主**发布，所以修饰类记号的局部变换一律作用到宿主，与它画在上方还是下方无关
        - 反过来把记号写成宿主（`$accent ^ 1`）就够不到其它成员，这不是 bug 而是同一条规则
        - 力度这类**持续状态**记号不受此限，写在宿主上方或下方都生效（`1 ^ $p`、`1 _ $p`）；但把记号自己当宿主就轮不到其它成员了（`$p ^ 1` 里宿主本音不变，之后的音才变弱），与 `@key` 同一条规则

### `^` 和 `&` 的区别
两者都是「往上叠」，但机制不同，只有在「单音符、等时长」这一种情形下看起来一样：

| | `^` / `@up` | `&` / `@stack` |
| --- | --- | --- |
| 产物 | **一个**事件（成员折叠进同一个盒子） | **多个**事件，各占一条纵向基线 |
| 成员时值 | 强制统一为第一个成员的时值 | 各分支独立，可以不同长短 |
| 能否整体当一个符号用 | 能（可以做倚音、连音线端点） | 不能，放进倚音会报 `E_GRACE_PARALLEL_CONTENT` |
| 典型用途 | 和弦、文本 | 临时伴奏、临时多声部 |

- `@arp(content, direction)` / `@arpeggio(...)` 琶音
    - content 必须是同一音轨、至少两个成员组成的 `@up` / `@down` 折叠体，例如 `@arp({1 ^ 3 ^ 5})`
    - 省略 direction：只画无箭头波浪线，播放仍按视觉位置从下到上依次延迟成员
    - `direction=up`：按视觉位置从下到上依次延迟成员，在波浪线顶端画向上箭头
    - `direction=down`：按视觉位置从上到下依次延迟成员，在波浪线底端画向下箭头
    - 每个成员都占一个延迟槽，无论它是否发声；只错开音符事件，速度、音色等系统状态仍在和弦时刻生效
    - 相邻槽默认错开 `1/8 QN`；短和弦会压缩间隔，使最后一个槽不晚于总时值的一半

- `@grace(宿主, 倚音, side=pre)` 倚音
    - 语法糖：`>` 与 `<`，**箭头永远指向宿主**
    - `2>1` 前倚音：`2` 画在 `1` 的左上角；`1<2` 后倚音：`2` 画在 `1` 的右上角
    - 多个倚音用大括号：`{3 2}>1`；相邻倚音的减时线会自动连成整条
    - 允许嵌套：`1>2>3` 表示 1 是 2 的倚音、2 是 3 的倚音，字号逐层缩小（`>` 左结合，`<` 右结合）
    - 倚音比宿主小一号，嵌套时逐层相乘；宿主与倚音各自只能产生可见事件，宿主必须恰好一个
    - 倚音**默认就是八分音符**（自带一条减时线），再写一个 `/` 变成十六分音符
    - 倚音不进入时间流：整体时值等于宿主时值，小节线、拍位、自动连梁都不受影响
    - 播放时倚音从宿主借时值：`比例 = 倚音字面总时值 / 四分音符`，基准取宿主经 div 与 dot 之后的实际时值，上限 0.75
    - 写在宿主或倚音成员上的标签保留在该成员：`@grace({1},{2@x})` 中 `x` 连接倚音 `2`
    - 写在 grace 调用后的标签穿透到宿主的可标注节点：`@grace({1},{2})@x` 中 `x` 连接宿主 `1`

- `@tuplet(content, normal)` 多连音
    - 从内容自动推导最短正时值 `shortest` 和原总时值 `writtenTotal`
    - 连音数字 `actual = writtenTotal / shortest`，必须是大于等于 2 的整数
    - 缩放后总时值为 `shortest * normal`，即所有成员的时间统一乘以 `normal / actual`
    - `@tuplet({1/23}, 4)` 中原时值为 `1/2 + 1 + 1 = 5/2 QN`，共 5 个最短单位；缩放后总时值为 `2 QN`，上方显示数字 5
    - 内容必须位于同一音轨和同一谱面行；允许嵌套，外层括线会避让先生成的内层括线

- `@note(...)` / `@n(...)`
    - 音名：`A B C D E F G`
    - 可见休止：`0`（`Z` 等价 `0`）
    - 隐形占位：`8`
    - 只打拍不发音：`9` 或 `X`，均显示为 `X`（不显示升降号和八度点）
    - 升降符：`#` `b` `n`（可重复，如 `bb`、`###`）
- `@div(内容, n=1, autobeam=true)` / `@/(...)`
    - 语法糖：直接在后面加`/`，可多个
    - 同一个 `div` 内容中的减时事件始终连接，与 `autobeam` 无关
    - 默认自动连接同轨、连续、同一逻辑行且位于同一四分音符拍内的独立 `div`，例如 `1/ 2// 3/`
    - 自动连接在拍边界、小节线、显式换行、时间间隙、同轨可见非候选元素、普通长事件、开关变化或手工 `@beam` 处结束
    - `autobeam=false` 关闭**该 div** 与周围 div 的自动连接，内部减时线仍然连接
- `@dot(...)` / `@.(...)`
    - 语法糖：直接在后面加`.`，可多个
    - 内容在 lowering 后必须恰好产生一个事件；`up/down` 折叠体算一个，所以 `{1^2}.`、`{1_2}.` 合法，并分别等价于 `{1.^2}`、`{1._2}`
- `@dash()` / `@-()`
    - 语法糖：直接在后面加`-`，可多个
- `@bar(...)` 创建一个小节线，时间线上强制对齐
    - `|:` 标记反复起点，`:|` 回到此前最近的反复起点；没有起点时回到曲首
    - 每条 `:|` 只回跳一次，连续写多条即可增加遍数
    - 重叠反复按最近起点解释：`|: 1 |: 2 :| 3 :|` 播放为 `1 2 2 3 2 3`
- `@text(内容, size=1em, lineheight=1.25, align=left)` 文本标记
    - 语法糖：`"渐强"` 等价于 `@text(渐强)`；引号内的逗号和右括号不再是参数分隔符
    - 括号内可以直接换行，`lineheight` 是相对自身字号的倍数
    - `align=left`（默认）各行左对齐，锚点在第一行首字符中心，单字标记因此能像音符一样对准宿主
    - `align=center` 各行居中，锚点取整块中心，适合多行标题
    - `align=right` 各行右对齐，锚点取第一行末字符中心，适合谱头作者栏
    - 受预处理规则影响：行尾奇数个 `\` 会把换行当续行吃掉，不加引号时第二行的 `%` 会开启行注释
- `@symbol(name, size=0.5em)` 乐谱符号容器
    - 语法糖：`$name`，名称必须以 ASCII 字母开头，后续可含字母、数字、`_` 和 `-`
    - 名称按小写查询内置符号表；未知名称抛出 `E_UNKNOWN_SYMBOL`
    - 每个符号是 `src/functions/symbol/symbols/` 下的一个对象字面量：固定图形加可选播放规则，符号之间互不依赖
    - 两处例外：力度记号族由 m/f/p 三个字母横向拼接、共享一条力度阶梯，合住 `symbols/dynamics.ts`；`$ds` 要知道往哪里跳，所以单向引用 `$segno` 的标记常量
    - 符号高度 = `size × weight`，`weight` 由符号自己声明，用来修正宽扁字形的视觉重量
    - `$fine` 不是固定图形而是交给宿主字体绘制的文字记号，字号同样是 `size × weight`
    - 内置记号：`$tr`（颤音）、`$fermata`（延长记号）、`$prall`（上波音）、`$mordent`（下波音）、`$accent`（重音）
    - 内置力度：`$ppp` `$pp` `$p` `$mp` `$mf` `$f` `$ff` `$fff`，velocity 依次为 16/32/48/64/80/96/112/127，`$mf` 恰好是默认力度
    - 内置反复：`$dc`（从头反复）、`$ds`（从记号处反复）、`$segno`（反复记号，D.S. 的回跳目标）、`$fine`（终止记号）
    - 持续类记号按**记谱位置**生效，从它所在位置一直到下一个同类记号；反复回跳后用的是目标位置之前的那个值
    - 力度属于声部，只在**自己所在的音轨**上流动：`@stack({1 2}, {3 $p 4})` 里的 `$p` 不会压低上面那条旋律
    - 新声部继承分叉处父轨的力度，所以 `$f 1 @voices(...)` 里的 `$f` 会传给每个声部；一旦声部自己开始发声，就不再跟随父轨的后续变化
    - 修饰类记号只作用于同一 `up` 中排在符号下方的成员，独立写出时只绘制：重音 velocity `+20`、`$tr` 在本音与调内上方二度间交替、`$prall` 为本音—上方音—本音、`$mordent` 为本音—下方音—本音（命名同 LilyPond）
    - 延长记号把目标音覆盖区间的速度减半；NoteOn/NoteOff 的 QN 位置不变，实际秒数翻倍
    - 装饰音的交替密度按发声时的速度决定（落在 8~64 Hz），默认速度下恰好是 `1/8` 四分音符
    - `$dc` 只在第一次到达时跳回曲首，第二次经过就正常收尾，所以整首曲子恰好演两遍；回跳后的那一遍不再重复曲中的 `|: :|`
    - `$ds` 同理，但跳回它之前最近的 `$segno`；谱里没写 `$segno` 时退回曲首，等价于 `$dc`
    - `$fine` 按“它后面最近的那个 `$dc` / `$ds` 是否已经跳过”判断是否收尾，所以写在 `|: :|` 里也不会被反复线提前触发；后面没有回跳记号时它不生效
    - 跟 `:|` 一样，这三个记号所在的时间列在跳转或收尾的那一遍不发声，所以应该写在小节线上下（`| _$dc`）而不是叠在音符上
- `@volta(from, to, pass, ...)` 反复房子：一段只在指定遍数演奏的区间
    - `from` `to` 是区间首末音符的标签，两者可以是同一个；写顺序不限，按时间列取 min/max
    - 遍数必填（房子上的数字本来就是谱面的一部分），必须是正整数，否则抛 `E_VOLTA_INVALID_PASS`。可以再跟任意多个遍数表示**几遍共用一个房子**，如 `@volta(a, b, 1, 2)`；重复和乱序都会被规整，标签按升序写成 `1.2.`
    - 不指向任何具体的反复线，属于哪个反复段完全由区间位置决定，每段的遍数各自从第一遍数起
    - 同一列被两个房子标成互斥的遍数时它一遍都不会演，报 `W_PLAYBACK_COLUMN_NEVER_PLAYED`
    - 按记谱惯例，括线两端会贴到相邻小节线的锚点上（相邻列不是小节线时才按内容取边）
- `@dyn(from, to, dv)` 渐强渐弱
    - `from`、`to` 是同一音轨上两个不同时间的标签；参数书写顺序不限，始终按记谱时间从早到晚生效
    - `dv` 是非零力度增量：正数渐强，负数渐弱；有限值超出 -127~127 时会被限制并产生警告；起点增量为 0，终点增量为完整 `dv`，中间按记谱时间线性插值
    - 增量叠加在每个音符已经固化的力度上，所以区间内的 `$p`、`$f` 仍独立生效，曲线可以在该处跳变
    - 终点后的完整增量保持到下一次原始力度变化；最终力度钳在 1~127，不在核心层取整
    - 楔形线画在数字上方，闭区间覆盖起点主体左边界到终点主体右边界；两个端点列也参与避让
    - 区间内的高对象和先声明且横向重叠的 attachment 会把楔形线向外推；后声明者排在外层
    - dyn 不特判或移动 `$p`、`$f`；要把力度记号放在楔形线两侧，可将它们写在区间外相邻音符上，如 `1 ^ $p 2@a 3@b 4 ^ $f @dyn(a,b,48)`
- `@br(offset=1)` 在后续事件前偏移指定行数
    - `offset` 是第一个位置参数，因此通常写作 `@br(2)`
    - 默认值为 1；按非负整数固化，小数向下取整，负数视为 0
    - `@br(0)` 不换行，`@br(2)` 会保留一个空行
    - 每次调用独立生效，多个 br 暂不合并
- `@adjust(内容, dx=0px, dy=0px, dw=0px, dh=0px)` 手工微调排版盒
    - `dx`/`dy` 在排版完成后平移，邻居不会让开，因此可以故意重叠；关系函数读取的是平移后的盒子，连音线等会跟着走
    - `dw`/`dh` 在排版之前增减占位，邻居会跟着让开或收拢，最终宽高不会小于 0；`dw` 按原左右占位比例分配，`dh` 只调整下方
    - 括住多个对象时逐个施加同一增量；括住的若是关系对象且其中没有对象，平移的就是这条关系对象
    - `@up`、`@grace` 的内部成员可以微调，尺寸增量按复合体原有盒模型反馈给外层；`@up` 的横向宽度仍只取最下面的成员

注意：简谱中永远先减时线作用，再加上附点，无论函数作用先后

### 关系型
参数类型为标签，如果不传，则默认取最后两个注册的节点(比如note)
- `@beam(...)`：手工连接传参的减时线；不受 `div.autobeam` 开关影响。参数必须按时间顺序对应同轨、同谱面行中的相邻可见元素；over 只有第一参数内的元素可参与外层 beam
- `@tie(...)`：按参数顺序连接元素；跨轨端点仍绘制连音线，但播放时只有同轨、同音且连续的音符才合并。近距离使用普通弧线，远距离或跨行时使用带水平段的连音线

语法糖实例：
- `"渐强"` -> `@text(渐强)`
- `@bar(C1 C3)` -> `@bar({ C1 C3 })`
- `{...}//` -> `@div({ ... }, 2)`
- `{...}.` -> `@dot({ ... }, 1)`
- `-` -> `@dash()`
- `--` -> `@dash() @dash()`
- `$fermata` -> `@symbol(fermata)`（需要 registry 中已有 `fermata` 定义）
- `C1 C3# |` -> `@note(C,1) @note(C,3,#) @bar()`

## 5. 预处理规则（换行与注释）
以下规则由 `src/parser/preprocess.ts` 在词法预处理阶段执行。所有替换都保持等长（用空格替换），以保证 offset 稳定。

- 注释规则：`%` 在非字符串上下文下表示行注释起点，作用到行尾（不含换行）。
- 字符串上下文要求双引号**配对**（`\` 转义的引号不算闭合）；找不到闭引号时该 `"` 只是普通字符，不会影响后文的注释识别。字符串可以跨行。
- `\%` 不会转义注释符：反斜杠不会阻止 `%` 开启注释。
- 换行识别：支持 `\n`、`\r\n`，兼容 `\r`；`lineStarts` 以逻辑换行为单位记录下一行起点。
- 行尾连续反斜杠规则：
  1. 对每一行，从行尾向前找最后一个非换行空白字符；若它属于连续 `\` 块，块长度记为 `n`。
  2. 连续块中的第 1/3/5/... 个 `\` 替换为空格，第 2/4/6/... 个保留。
  3. 若 `n` 为奇数，则该行换行符也替换为空格（续行）。
  4. 若 `n` 为偶数，则不续行（换行保留）。
- SourceSpan 统一按左闭右开 `[start, end)` 理解。
