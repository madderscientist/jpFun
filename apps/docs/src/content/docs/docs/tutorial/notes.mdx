上一章介绍了 jpFun 的函数调用。这一章只关注最基本的音符：先从 `@note` 的完整定义出发，再把它缩写成日常写谱时使用的简洁记号。还会介绍数字音名与字母音名的区别，以及调性的设置。

## `@note` 函数

音符由 `@note` 函数创建，它还有一个较短的别名 `@n`：

```jpfun
@note(name, acc="", octave=4, color="#000")
```

| 参数 | 含义 |
| --- | --- |
| `name` | 必填。可以是数字音名 `1`～`7`，也可以是字母音名 `A`～`G` |
| `acc` | 升降记号，默认为空。`#` 升高半音，`b` 降低半音，`n` 显示还原号，可以连续写多个 |
| `octave` | 八度。数字音名使用相对八度，默认 `0`；字母音名使用绝对八度，默认 `4` |
| `color` | 音符颜色，默认为 `#000`（黑色） |

下面的谱例完全使用函数调用。第一小节是数字音名，第二小节是字母音名：

export const noteFunctionExample = `\
@note(1)        @note(2, "#")    @note(3, "bb", 1) |
@note(C, "", 4) @note(D, "#", 4) @note(E, "bb", 5, #f00) |`;

<ScoreExample title="使用 @note 创建音符" source={noteFunctionExample} />

`name` 还有几个特殊取值：
- **可见休止符**：`0`（或 `Z`）
- **节拍记号**：`9`（或 `X`）是显示为 `X`、播放为短促打击音的节拍记号
- **占位符**：`8` 不显示也不发声，但是推进时间

这三个特殊取值时，`acc` 和 `octave` 参数会被忽略。

export const specialNoteExample = `\
% 三个特殊取值只有 name 参数有效
@n(0, "#")            % 可见休止符，acc 参数会被忽略
@n(8, octave=9)       % 占位符，octave 参数会被忽略
@n(9, color="#00f")   % 节拍记号，color 参数会被忽略`;

<ScoreExample title="特殊音符示例" source={specialNoteExample} />

## 数字音名与字母音名
`name` 参数支持写数字和字母。数字音名与字母音名的区别在于它们确定实际音高的方式。简单来说，数字音名忠于视觉，适合打谱；字母音名忠于音高，适合转调。

### 数字音名是相对音高
简谱中，一个数字音名的音高并不是绝对的，而是和调性相关的。比如，在 D 大调中，数字 `1` 其实是钢琴上的 `D4`，频率约为 293.66 Hz。jpFun 吸纳了这个记录方法，`1`～`7` 表示相对于当前调性基准的音级。

因此必须有一个“`1` 是什么音”的基准。这个基准由 [`@key` 函数](../../reference/#key) 的 `tonality` 参数设置，含义为**调性**：
```jpfun
@key(tonality=C4)   % 默认基准是 C4
```

`tonality` 写成“字母音名 + 可选升降号 + 绝对八度”，例如 `C4`、`F#3`、`Bb4`；省略八度时默认为第 4 八度。例如，`@key(C4)` 表示以中央 C（`C4`）作为 `1`，`@key(D5)` 则表示以 `D5` 作为 `1`。`@key` 还有一个符合简谱习惯的别名 `@1`，所以 `@1(D4)` 与 `@key(D4)` 完全相同。尚未调用 `@key` 时，默认基准是 `C4`。

`@key` 从它出现的位置开始影响后面的数字音名：

export const relativePitchExample = `\
@key(C4) @note(1) @note(2) @note(3) |
@key(D5) @note(1) @note(2) @note(3) |`;

<ScoreExample title="数字音名跟随 tonality 基准" source={relativePitchExample} />

> `@key` 渲染的效果是 “1=\<tonality\>”，上面例子中和旋律排在了一行，而实际应该在音符上方。排布在上方需要使用 `@up` 函数，本章就不介绍了。

两小节都写成 `1 2 3`，但播放的时候会发现，第二小节的实际音高整体比第一小节高八度又一个大二度。

数字音名的 `octave` 也是相对基准计算的。`@note(1, "", 1)` 比当前基准高一个八度（对应简谱：上方加一个点），`@note(1, "", -1)` 则低一个八度。

也就是说，如果使用数字音名，能保证渲染后的简谱看起来和脚本一样，但是演奏的音高却会变化。如果你希望 jpFun 忠于视觉，请使用数字音名。

### 字母音名是绝对音高
`A`～`G` 直接指定绝对音名，`octave` 使用绝对八度编号。例如 `@note(C, "", 4)` 始终是 `C4`，音高不会因为 `tonality` 的改变而改变。但此时渲染出的简谱显示的数字会根据当前的调性进行换算：

export const pitchModeComparison = `\
@key(C4) @n(1) @n(C, "", 4) |
@key(D5) @n(1) @n(C, "", 4) |`;

<ScoreExample title="相对音高与绝对音高" source={pitchModeComparison} />

第一小节中，数字 `1` 和字母 `C4` 是同一个实际音高，频率约为 261.63 Hz（中央 C）。切换到 `D5` 基准后，数字 `1` 变成 `D5`（频率约为 587.33 Hz），而字母音名 `@n(C4)` 的音高仍然是 `C4`。

基于“字母音名忠于音高”这个特性，**字母音名记谱适合转调**。编辑器导入 MIDI 或者 MusicXML 时就是用了绝对音名记谱。此时只需要改动最前面的 `@key` 函数，就可以整体移调，只改变视觉，不影响演奏效果。

## 音符的语法糖
完整函数调用适合精确控制参数，但逐个写会很长。`@note` 因此提供了紧凑的语法糖：直接写音名，就等于调用一次 `@note`。

| 函数调用 | 语法糖 | 含义 |
| --- | --- | --- |
| `@note(1)` | `1` | 当前基准上的第一级 |
| `@note(2, "#")` | `#2` | 升高半音的第二级 |
| `@note(3, "", 2)` | `3''` | 高两个相对八度的第三级 |
| `@note(6, "b", -1)` | `b6,` | 低一个相对八度、再降半音的第六级 |
| `@note(C, "", 4)` | `C4` | 绝对音高 C4 |
| `@note(F, "#", 5)` | `F#5` | 绝对音高 F♯5 |

数字音名后每写一个英文单引号 `'`，就升高一个八度；每写一个英文逗号 `,`，就降低一个八度。字母音名则直接在末尾写绝对八度编号。数字音名的升降号需要写在音名前，例如 `#1'`、`b3,`；字母音名则需要写成 `C#4`、`Bb3`。此外，简写也可以直接作为函数调用写法中，`name` 的传参。

下面两小节的音高完全相同，前一小节使用完整函数，后一小节使用语法糖：

export const noteSugarExample = `@key(C4)   % 调性的写法就是数字音高的简写\n
@note(1) @note(2, "#") @note(3, "", 2) @note(6, "b", -1) @note(C, "bb", 2) |
1 #2 3'' @note("b6,") Cbb2 |`;

<ScoreExample title="完整函数与语法糖" source={noteSugarExample} />

> `@note("b6,")` 之所以要加引号，是因为音名中包含了逗号，直接写作 `b6,` 会被解析为多个参数，而加上引号后会被作为单个字符串参数传入 `name`。

日常写谱时优先使用语法糖即可；需要设置 `color` 等简写没有表达的参数时，再使用完整的 `@note(...)`。完整参数和默认值也可以随时在[函数速查](../../reference/#note)中查看。

## JE 谱兼容
jpFun 还兼容 [JE 谱](https://github.com/zytx121/je#je%E8%B0%B1) 用括号表示八度的写法：小括号 `(...)` 内的音符整体降低一个八度，中括号 `[...]` 内的音符整体升高一个八度：

export const jeCompatibilityExample = `\
(1 2 3) [4 5 6] |
1, 2, 3, 4' 5' 6' |`;

<ScoreExample title="JE 谱括号与八度记号" source={jeCompatibilityExample} />

这两小节的音高完全相同。括号可以嵌套，每多一层就再改变一个八度，例如 `((1))` 等价于 `1,,`，`[[1]]` 等价于 `1''`。不过注意，括号的作用范围被“内容块”范围限制。

## 小结
- `@note` 创建音符，`@n` 是它的别名。
- 数字音名是相对音高，基准由 `@key` 的 `tonality` 参数设置；`@1` 是 `@key` 的别名。
- 字母音名是绝对音高，不会随 `tonality` 移调，但会按当前调性换算成简谱数字显示。
- `1`、`#2'`、`C#5` 等写法都是 `@note(...)` 的语法糖。
