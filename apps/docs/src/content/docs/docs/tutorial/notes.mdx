前两章介绍了 jpFun 的函数调用，以及参数的六种基本类型。这一章只关注最基本的音符：先从 `@note` 的完整定义出发，再把它缩写成日常写谱时使用的简洁记号。还会介绍数字音名与字母音名的区别，以及调性的设置。

## 注释
在正式介绍音符之前，我们先了解一下**注释**的写法。后面的谱例会用注释在代码旁边加上说明，帮助你理解每一行的作用。

注释用 `%` 开头，从 `%` 到这一行结束的内容都是给人看的说明，不会影响乐谱：

```jpfun
% 这里是注释
1 2 3 % 这里也是注释
```

删掉这些注释，仍然会得到相同的三个音符。除了说明，你还可以通过注释来临时失效某些代码。

> 在编辑器中，使用 `Ctrl+/` 可以快速添加或取消注释。

## `@note` 函数

音符由 `@note` 函数创建，它还有一个较短的别名 `@n`：

```jpfun
@note(name, acc="", octave=4, color="#000", force=false, carry=false)
```

| 参数 | 类型 | 含义 |
| :---: | :---: | --- |
| `name` | 字符串 | 必填。可以是数字音名 `1`～`7`，也可以是字母音名 `A`～`G` |
| `acc` | 字符串 | 升降记号，默认为空。`#` 升高半音，`b` 降低半音，`n` 显示还原号，可以连续写多个 |
| `octave` | 数值 | 八度。数字音名使用相对八度，默认 `0`；字母音名使用绝对八度，默认 `4` |
| `color` | 字符串 | 音符颜色，默认为 `#000`（黑色） |
| `force` | 布尔 | 强制显示变音号，默认 `false`。见[强制显示变音号](#强制显示变音号) |
| `carry` | 布尔 | 只能按名称传入。变音记号对本小节后面的同音也生效，默认 `false`。见[变音记号的作用范围](#变音记号的作用范围) |

下面的谱例完全使用函数调用。第一小节是数字音名，第二小节是字母音名：

export const noteFunctionExample = `\
@note(1)        @note(2, "#")    @note(3, "bb", 1) |
@note(C, "", 4) @note(D, "#", 4) @note(E, "bb", 5, #f00) |`;

<ScoreExample title="使用 @note 创建音符" source={noteFunctionExample} />

`name` 还有几个特殊取值：
- **可见休止符**：`0`（或 `Z`）
- **节拍记号**：`9`（或 `X`）是显示为 `X`、播放为短促打击音的节拍记号
- **占位符**：`8` 不显示也不发声，但是推进时间

这三个特殊取值时，`acc` 和 `octave` 参数会被忽略。

export const specialNoteExample = `\
% 三个特殊取值只有 name 参数有效
@n(0, "#")            % 可见休止符，acc 参数会被忽略
@n(8, octave=9)       % 占位符，octave 参数会被忽略
@n(9, color="#00f")   % 节拍记号，color 参数不会被忽略，因为和音高没关系`;

<ScoreExample title="特殊音符示例" source={specialNoteExample} />

## 数字音名与字母音名
`name` 参数支持写数字和字母。数字音名与字母音名的区别在于它们确定实际音高的方式。简单来说，数字音名忠于视觉，适合打谱；字母音名忠于音高，适合转调。

### 数字音名是相对音高
简谱中，一个数字音名的音高并不是绝对的，而是和调性相关的。比如，在 D 大调中，数字 `1` 其实是钢琴上的 `D4`，频率约为 293.66 Hz。jpFun 吸纳了这个记录方法，`1`～`7` 表示相对于当前调性基准的音级。

因此必须有一个“`1` 是什么音”的基准。这个基准由 [`@key` 函数](../../reference/#key) 的 `tonality` 参数设置，含义为**调性**：
```jpfun
@key(tonality=C4)   % 默认基准是 C4
```

`tonality` 写成“字母音名 + 可选升降号 + 绝对八度”，例如 `C4`、`F#3`、`Bb4`；省略八度时默认为第 4 八度。例如，`@key(C4)` 表示以中央 C（`C4`）作为 `1`，`@key(D5)` 则表示以 `D5` 作为 `1`。`@key` 还有一个符合简谱习惯的别名 `@1`，所以 `@1(D4)` 与 `@key(D4)` 完全相同。尚未调用 `@key` 时，默认基准是 `C4`。

`@key` 从它出现的位置开始影响后面的数字音名：

export const relativePitchExample = `\
@key(C4) @note(1) @note(2) @note(3) |
@key(D5) @note(1) @note(2) @note(3) |`;

<ScoreExample title="数字音名跟随 tonality 基准" source={relativePitchExample} />

> `@key` 渲染的效果是 “1=\<tonality\>”，上面例子中和旋律排在了一行，而实际应该在音符上方。排布在上方需要使用 `@up` 函数，本章就不介绍了。

两小节都写成 `1 2 3`，但播放的时候会发现，第二小节的实际音高整体比第一小节高八度又一个大二度。

数字音名的 `octave` 也是相对基准计算的。`@note(1, "", 1)` 比当前基准高一个八度（对应简谱：上方加一个点），`@note(1, "", -1)` 则低一个八度。

也就是说，如果使用数字音名，能保证渲染后的简谱看起来和脚本一样，但是演奏的音高却会变化。如果你希望 jpFun 忠于视觉，请使用数字音名。

### 字母音名是绝对音高
`A`～`G` 直接指定绝对音名，`octave` 使用绝对八度编号。例如 `@note(C, "", 4)` 始终是 `C4`，音高不会因为 `tonality` 的改变而改变。但此时渲染出的简谱显示的数字会根据当前的调性进行换算：

export const pitchModeComparison = `\
@key(C4) @n(1) @n(C, "", 4) |
@key(D5) @n(1) @n(C, "", 4) |`;

<ScoreExample title="相对音高与绝对音高" source={pitchModeComparison} />

第一小节中，数字 `1` 和字母 `C4` 是同一个实际音高，频率约为 261.63 Hz（中央 C）。切换到 `D5` 基准后，数字 `1` 变成 `D5`（频率约为 587.33 Hz），而字母音名 `@n(C4)` 的音高仍然是 `C4`。

基于“字母音名忠于音高”这个特性，**字母音名记谱适合转调**。编辑器导入 MIDI 或者 MusicXML 时就是用了绝对音名记谱。此时只需要改动最前面的 `@key` 函数，就可以整体移调，只改变视觉，不影响演奏效果。

## 音符的语法糖
完整函数调用适合精确控制参数，但逐个写会很长。`@note` 因此提供了紧凑的语法糖：直接写音名，就等于调用一次 `@note`。

| 函数调用 | 语法糖 | 含义 |
| --- | --- | --- |
| `@note(1)` | `1` | 当前基准上的第一级 |
| `@note(2, "#")` | `#2` | 升高半音的第二级 |
| `@note(3, "", 2)` | `3''` | 高两个相对八度的第三级 |
| `@note(6, "b", -1)` | `b6,` | 低一个相对八度、再降半音的第六级 |
| `@note(C, "", 4)` | `C4` | 绝对音高 C4 |
| `@note(F, "#", 5)` | `F#5` | 绝对音高 F♯5 |

数字音名后每写一个英文单引号 `'`，就升高一个八度；每写一个英文逗号 `,`，就降低一个八度。字母音名则直接在末尾写绝对八度编号。推荐把数字音名的升降号写在音名前，例如 `#1'`、`b3,`；字母音名写成 `C#4`、`Bb3`。此外，简写也可以直接作为函数调用写法中 `name` 的传参。

> 为了兼容番茄简谱的习惯，**无歧义**时也接受后置升降号：`6#,,` 等价于 `#6,,`，`A3#` 等价于 `A#3`。歧义情况：`6#3` 依然被解析为 `6` 和 `#3`，除非加空格分隔。

下面两小节的音高完全相同，前一小节使用完整函数，后一小节使用语法糖：

export const noteSugarExample = `@key(C4)   % 调性的写法就是数字音高的简写\n
@note(1) @note(2, "#") @note(3, "", 2) @note(6, "b", -1) @note(C, "bb", 2) |
1 #2 3'' @note("b6,") Cbb2 |`;

<ScoreExample title="完整函数与语法糖" source={noteSugarExample} />

> `@note("b6,")` 之所以要加引号，是因为音名中包含了逗号，直接写作 `b6,` 会被解析为多个参数，而加上引号后会被作为单个字符串参数传入 `name`。

日常写谱时优先使用语法糖即可；需要设置 `color` 等简写没有表达的参数时，再使用完整的 `@note(...)`。完整参数和默认值也可以随时在[函数速查](../../reference/#note)中查看。

## 高八度号与低八度号
一段旋律整体升降八度演奏时，可以用 `@ottava` 标出范围，而不必给每个音符加八度点：
```jpfun
@ottava(a, b, shift=1)
```

`a`、`b` 是首末元素的标签，只能按位置传入；`shift` 是非零整数八度数，可按位置或名称传入，正数表示高、负数表示低，默认 `1`。

export const ottavaExample = `\
5,/@highStart 6,/ 1/ 2/ | 5 -@highEnd |
@ottava(highStart, highEnd)
5'/@lowStart 6'/ 1/ 2/ | 5 -@lowEnd |
@ottava(lowStart, lowEnd, shift=-1)
1@doubleStart 2 3 4@doubleEnd |
@ottava(doubleStart, doubleEnd, 2)
1@tripleStart 2 3 4@tripleEnd |
@ottava(tripleStart, tripleEnd, -3)`;

## 变音记号的作用范围
**默认情况下，jpFun 的变音记号只作用于当前音符。** 例如在 C 调中，`#1 1` 是升高半音的 `1` 和普通的 `1`；如果两个音都要升高，请写成 `#1 #1`。

简谱国家标准规定，变音记号对本小节后面的同度音同样有效，对八度同名音无效。需要按这条规则读谱时，用 `@note` 的 `carry` 参数开启**变音延续**：

```jpfun
@set(note.carry=true)              % 从这里往后开启
{@set(note.carry=true) #1 1 1 1}   % 只在花括号内开启
#1 @n(1, carry=true) 1             % 只对一个音开启
```

开启后，jpFun 为每个声部记住本小节内已显示的变音记号（`#`、`b`、`n`），小节线或 `@key` 处清空。两种音名各自保持一件事不变：
- **数字音名所见即所写**：谱面与源码完全一致，播放时按本小节前文的记号读。`#1 1` 显示不变，第二个音播放为 C♯；要回到 C 需写成 `#1 n1`。
- **字母音名所听即所写**：播放与源码完全一致，显示时自动省略或补上记号。`C#4 C#4 C4` 显示为 `#1 1 n1`。

export const accidentalCarryExample = `\
#1 1 | {
@set(note.carry=true) #1 1 1' n1 1
} | #1 @n(1, carry=true) 1 |
@set(note.carry=true)
C#4 C#4 C4 C#4 | @key(D4) F#4 F4 F4 F#4 |`;

<ScoreExample title="变音延续" source={accidentalCarryExample} />

第一行的三个小节分别演示未开启、在花括号内开启、只对中间一个音开启，依次播放 C♯ C | C♯ C♯ C5 C C | C♯ C♯ C，其中 `1'` 是八度同名音，不受升号影响。第二行显示为 `#1 1 n1 #1 | 3 b3 3 n3`。

与其他功能的关系：
- **和弦**：同时发生的音互不影响，`1 ^ #1` 中的 `1` 仍是 C；记号对后面的音生效。
- **倚音**：倚音主线与宿主声部共用记忆，按时间先后生效，例如 `{#1 1}>2 1` 的最后一个 `1` 也是 C♯。前倚音早于同列的音，`1 ^ {#1>2}` 中的 `1` 是 C♯；后倚音晚于同列的音，`1 ^ {2<#1}` 中的 `1` 仍是 C。倚音中用 `&` 分出的额外声部单独记忆。
- **多声部**：每个声部独立记忆，互不影响。
- **延音线**：同一小节内照常生效，`#1 1@tie()` 合并为一个 C♯；跨小节不延续，见下文。
- **音高编辑**：编辑器把数字音名升降半音时，会给受影响的后续音补上记号，保持其他音的音高不变，例如把 `1 1` 的第一个音升高得到 `#1 n1`。

与国家标准的差异：
- **默认关闭**：未开启 `carry` 时，变音记号只作用于当前音符。
- **延音线跨小节不延续变音**：标准规定，延音线跨小节连接的同音延续变音效力，且只延续到被连接的这个音。jpFun 不做这种延续：`#1 | 1@tie()` 的第二个音按 C 播放，两端音高不同，不会合并，会重新发声。要连成 C♯，请写成 `#1 | #1@tie() n1`，其中 `n1` 让后面的同音回到 C。字母音名会自动显示成这种写法，比标准写法多一个升号和一个还原号，但不会读错。

> 建议只在小节线处切换 `carry`。在小节中途从开启切换为关闭时，关闭的音不会读前文记号，谱面与播放可能不一致。

### 强制显示变音号
`@note` 的 `force` 参数强制显示这个音**实际生效**的变音号，常用来写提示性变音号。它只影响显示，不改变音高；没有变音时显示还原号 `n`。

和 LilyPond 一样，`force=true` 可以简写为音名末尾的 `!`，写在八度记号之后，例如 `C#4!`、`#1'!`、`1,!`。`C4!` 等价于 `@note(C, "", 4, force=true)`；`!` 也可以写进 `name` 参数，例如 `@note(C!, "#", 4)`。

export const forcedAccidentalExample = `\
C4 C4! #1 1! |
@set(note.carry=true)
C#4 C#4 C#4! C4 | #1 1 1! n1 |`;

<ScoreExample title="强制显示变音号" source={forcedAccidentalExample} />

第一小节没有开启 `carry`，`C4!` 和 `1!` 都是 C，显示为 `n1`。第二小节开启了 `carry`，字母音名 `C#4` 第二次出现时省略升号，加上 `!` 后补回来，显示为 `#1 1 #1 n1`。第三小节的 `1!` 沿用前面的升号，播放为 C♯，显示为 `#1`。

未开启 `carry` 时，有变音的音本来就会显示记号，`force` 只对没有变音的音起作用：显示一个还原号。数字音名直接写 `n1` 效果相同；字母音名写 `Cn4` 仍显示为 `1`，只能写成 `C4!`。常见用法是提醒前一小节的变音已经失效，例如 `C#4 | C4!` 显示为 `#1 | n1`。

## JE 谱兼容
jpFun 还兼容 [JE 谱](https://github.com/zytx121/je#je%E8%B0%B1) 用括号表示八度的写法：小括号 `(...)` 内的音符整体降低一个八度，中括号 `[...]` 内的音符整体升高一个八度：

export const jeCompatibilityExample = `\
(1 2 3) [4 5 6] |
1, 2, 3, 4' 5' 6' |`;

<ScoreExample title="JE 谱括号与八度记号" source={jeCompatibilityExample} />

这两小节的音高完全相同。括号可以嵌套，每多一层就再改变一个八度，例如 `((1))` 等价于 `1,,`，`[[1]]` 等价于 `1''`。不过注意，括号的作用范围被“内容块”范围限制。

## 小结
- `@note` 创建音符，`@n` 是它的别名。
- 数字音名是相对音高，基准由 `@key` 的 `tonality` 参数设置；`@1` 是 `@key` 的别名。
- 字母音名是绝对音高，不会随 `tonality` 移调，但会按当前调性换算成简谱数字显示。
- `1`、`#2'`、`C#5` 等写法都是 `@note(...)` 的语法糖。
