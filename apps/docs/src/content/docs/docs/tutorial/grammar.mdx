上一章用 `1`、`2/` 等记号写出了简谱。它们看起来是专门的乐谱语法，本质上却是**函数调用的简写**。“函数调用” 是 jpFun 架构的核心与亮点：一切功能皆函数。为了保障平时写谱的便捷性，jpFun 为一些常用函数提供了简写（语法糖）。

简单来说，你只要学会怎么调用函数，你就解锁了 jpFun 的所有功能！本章我们就深度讲解函数调用的语法。

## 从简写到函数
先看几组等价的写法：

| 简写 | 函数调用 | 含义 |
| --- | --- | --- |
| `1` | `@note(1)` | 写一个音符 |
| `1//` | `@div(@note(1), 2)` | 给这个音符加两条减时线 |
| `1 ^ 3 ^ 5` | `@up(1, 3, 5)` | 把几个音叠成和弦 |
| `"轻快地"` | `@text("轻快地")` | 写一段文字 |

这里的“函数”可以理解为一条写谱指令：`note` 产生音符，`div` 缩短音符的时值，`text` 产生文字。括号里填写这条指令需要的信息，我们称之为“参数”。

语法糖（简写）和函数调用可以混用。例如下面四个音符都带一条减时线，只是写法不同：

<ScoreExample title="同一种能力，不同写法" source="1/ @div(2, 1) @div(@note(3), 1) 4/" />

日常写谱仍然可以优先使用简写，以获得更好的可读性。而使用函数的形式，可以进行更深度的定制（比如音符颜色），因为简写往往并不能完全覆盖一个函数的所有功能。

## 调用函数
函数调用形如 **`@函数名(参数1, 参数2, ...)`**，有以下规则**必须遵守**：
- 以 `@` 开头
- `@` 之后**紧跟**函数名
- 函数名后**紧跟**左括号 `(`（不允许有空格！）。结合上一条，也就是 `@` 和 `(` 之间的内容是函数名，且函数名不能有空格（为什么不能有空格？看完之后的“标签”类型你就懂啦）
- 参数之间用**英文逗号** `,` 分隔
- 最右边以右括号 `)` 结束

例如：
```text
@tempo(100)  % 设置速度为 100 BPM
@meter(4, 4) % 设置拍号为 4/4
@text("轻快地", size=0.8em) % 写一段文字并设置大小
```

前两例使用**位置参数**：`@tempo(100)` 把速度设为 100 BPM，`@meter(4, 4)` 的两个参数依次是拍号的分子和分母。

最后一例还使用了**命名参数** `size=0.8em`，直接指出要调整文字大小。**位置参数必须写在命名参数之前**；哪些参数可以省略、省略后使用什么值，由具体函数决定。命名参数未显式传入时，会先采用当前的 `@set` 设置（见set函数说明），再采用函数默认值。

不需要填写参数时，也要保留括号。例如 `@br()` 表示换到下一谱面行；只写 `@br` 不会调用函数。

## 参数里的值
参数不全是数字，也可以是文字、一段乐谱或对某个音符的引用。常见类型如下，具体如何解释由函数的参数类型决定：

| 类型 | 示例 | 用途 |
| --- | --- | --- |
| 字符串 | `"轻快地"`、`center` | 文字、名称和选项 |
| 布尔值 | `true`、`false` | 开启或关闭某个选项 |
| 数字 | `100`、`0.7`、`-12` | 速度、比例和其他数值 |
| 长度 | `12px`、`0.8em` | 字号、间距和页面尺寸；省略单位时默认为 `px` |
| 内容 | `{1 2 3 4}` | 把一段乐谱作为一个参数传入 |
| 标签 | `start`、`end` | 引用已经标记的对象 |

### 字符串与引号

字符串使用成对的英文双引号 `"`，不能用单引号代替，因为单引号已经用于八度记号。不会产生歧义时可以省略双引号，因此 `@text(轻快地)` 与 `@text("轻快地")` 效果相同。

如果文字里有英文逗号，就应保留引号：

```text
@text("稍快, 有活力")
```

引号让逗号成为文字的一部分，而不是参数分隔符。在乐谱正文中，单独写一段带双引号的文字，则是 `@text` 的语法糖。

### 内容块与嵌套

花括号 `{}` 把一段乐谱划为一个内容块。例如给两个音符一起加减时线：

<ScoreExample title="把一段内容交给函数" source="@div({1 2}, 1) 3 4" />

这里的 `{1 2}` 是第一个参数，`1` 是第二个参数，表示添加一条减时线。花括号本身不会换行，也不会创建新声部；内容如何处理取决于外面的函数。

内容在不产生歧义时可以省略花括号。刚开始写时，单个音符可以直接传入，一段内容则建议明确使用 `{}`，便于看清范围。

内容里也可以继续调用函数，这就是**嵌套**。例如下面两种写法等价：

```text
@div(@note(1), 1)
@div({@note(1)}, 1)
```

`@note(1)` 产生的音符作为内容交给 `@div`，效果就是本章开头的 `1/`。嵌套表达的是组合关系：把一种功能产生的内容，再交给另一种功能处理。

## 用标签引用音符

有些功能需要连接已经写下的对象，例如用 `@tie` 在两个音符之间画连音线。这类**关系函数**可以通过标签找到端点：

<ScoreExample title="用标签连接两个音符" source="1@start 2 3@end @tie(start, end)" />

这个例子分成两步：

1. `1@start` 给音符 `1` 标上 `start`，`3@end` 给音符 `3` 标上 `end`。
2. `@tie(start, end)` 使用这两个标签，在对应音符之间画线；参数里的标签名不带 `@`。

`@start` 和 `@end` 后面没有紧跟左括号，因此是标签而不是函数调用。标签绑定到它前面最近的可标注对象；标签名之后应留出空格，避免后面的音符被读成名字的一部分。

这也解释了上一章完整谱例中的 `2/@x 1/@y @tie(x,y)`：先给两个音符命名，再通过名字引用它们。具体关系函数怎样选择端点、什么时候可以省略标签，在对应功能中再展开。

## 注释

字符串之外的 `%` 会把从它开始到行末的内容变成注释。注释不会出现在乐谱中，适合记录写谱意图：

```text
1 2 3 4 | % 第一小节
5 6 7 1'
```

至此，读到一个新函数时，可以先看它接收什么类型的参数，再判断是产生内容、处理内容，还是引用已有对象。完整的参数、默认值和别名可随时查阅[函数速查](../../reference/)，不需要一次记住所有函数。
