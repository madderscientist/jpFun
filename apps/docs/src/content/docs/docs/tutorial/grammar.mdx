上一章用 `1`、`2/` 等记号写出了简谱。它们看起来是专门的乐谱语法，本质上却是**函数调用的简写**。“函数调用” 是 jpFun 架构的核心与亮点：一切功能皆函数。为了保障平时写谱的便捷性，jpFun 为一些常用函数提供了简写（语法糖）。

简单来说，你只要学会怎么调用函数，你就解锁了 jpFun 的所有功能！本章我们就深度讲解 jpFun 的语法，包括两部分：函数调用、基本类型。

## 注释
在开始前，先了解一下 jpFun 的注释写法。注释不会被解析器执行，只是给人看的说明文字。注释使用 `%` 开头，到行末的内容都会被视为注释。例如：

export const commentExample = `% 这是一个注释
@note(1) % 这也是注释
这段内容不是语法，也会被忽略
`;

<ScoreExample title="注释示例" source={commentExample} />

后文会多次用到注释，来解释脚本的作用。实际上，只要不是语法范围里的文本，都会被忽略；上面的例子中，第三行的内容就是被忽略的。

## 从简写到函数
先看几组等价的写法：

| 简写(语法糖) | 函数调用 | 含义 |
| --- | --- | --- |
| `1` | `@note(1)` | 写一个音符 |
| `1//` | `@div(@note(1), 2)` | 给这个音符加两条减时线 |
| `1 ^ 3 ^ 5` | `@up(1, 3, 5)` | 把几个音叠成和弦 |
| `"轻快地"` | `@text("轻快地")` | 写一段文字 |

“函数”可以理解为一条写谱指令：`note` 产生音符，`div` 缩短音符的时值，`text` 产生文字。括号里填写这条指令需要的信息，我们称之为“参数”。

语法糖和函数调用可以混用。例如下面四个音符都带一条减时线，只是写法不同：

<ScoreExample title="同一种能力，不同写法" source="1/ @div(2, 1) @div(@note(3), 1) 4/" />

日常写谱仍然可以优先使用简写，以获得更好的可读性。而使用函数的形式，可以进行更深度的定制（比如音符颜色），因为简写往往并不能完全覆盖一个函数的所有功能。

## 函数调用语法
函数调用形如 **`@函数名(参数1, 参数2, ...)`**，有以下规则**必须遵守**：
- 以 `@` 开头
- `@` 之后**紧跟**函数名
- 函数名后**紧跟**左括号 `(`（不允许有空格！）。结合上一条，也就是 `@` 和 `(` 之间的内容是函数名，且函数名不能有空格（为什么不能有空格？看完之后的“标签”类型你就懂啦）
- 参数之间用**英文逗号** `,` 分隔
- 最右边以右括号 `)` 结束。不需要填写参数时，也要保留括号。例如 `@br()` 表示换到下一谱面行；只写 `@br` 不会调用函数。

例如：
```text
@tempo(100)  % 设置速度为 100 BPM
@meter(4, 4) % 设置拍号为 4/4
@text("轻快地", size=0.8em) % 写一段文字并设置大小
```

前两例使用**位置参数**：`@tempo(100)` 把速度设为 100 BPM，`@meter(4, 4)` 的两个参数依次是拍号的分子和分母。“位置参数”顾名思义，就是按照顺序传递给函数的参数。比如 `@meter` 规定，第一个参数表示分子，第二个参数表示分母。

最后一例还使用了**命名参数** `size=0.8em`。命名参数的语法为：`参数名=值`。实际上，大多数参数都是有名字的，比如 `@meter` 的两个参数名字分别为 `num` 和 `den` （分子分母英文的缩写），上面的例子完全可以使用命名参数的形式写作 `@meter(num=4, den=4)`。

位置参数和命名参数可以混用，不过 **位置参数必须写在命名参数之前**，比如 `@meter(4, den=4)` 是对的，但 `@meter(num=4, 4)` 就是错的。

### 默认值
命名参数有两个好处：
1. 可读性更强：名字就蕴含了作用和含义。
2. 可以不按顺序传递参数，比如 `@meter(den=4, num=4)` 也是可以的。

第二点格外重要：跳过有默认值的参数。实际上，一个函数的参数可以有很多，比如 `@text` 的完整定义是这样的：

| 顺序 | 参数名 | 类型 | 含义 |
| --- | --- | --- | --- |
| 1 | 无 | 字符串 | 要显示的文本 |
| 2 | size | 长度 | 文字的大小 |
| 3 | lineheight | 长度 | 行高 |
| 4 | align | 字符串 | 对齐方式 |

> 如果没有参数名，意味着你必须使用位置参数来传递值。在上面的 `@text` 例子中，第一个参数没有名字，因此只能写在第一个。

但是，每次都要写四个参数也太长、太麻烦了吧！所以参数会有默认值，比如 `align` 的默认值就是 `left`，表示多行的时候靠左对齐。如果只有位置参数却要调整 `align`，就必须把前面所有参数都写上、并抄写一遍默认值——太麻烦了！此时如果用位置参数，就可以直接跳过，比如：
```text
@text("轻快地", align="center")   % 跳过了有默认值的 size 和 lineheight
```

默认值是 jpFun 开发者写死的；如果这些默认值不符合你的需求，难道要每次都传递吗？于是 jpFun 设计了 `@set` 函数，可以修改作用域内的默认值。它的调用方式如下：
```text
@set(text.align="center", meter.den=8)
```
参数名由两部分组成：前半部分是函数名，后半部分是函数的参数名，中间用点 `.` 连接。例如 `text.align` 表示 `@text` 函数的 `align` 参数。上面这段脚本的含义就是，之后 `@text` 函数的 `align` 参数默认值会被设置为 `"center"`，`@meter` 函数的 `den` 参数默认值会被设置为 `8`。

注意生效范围：`@set` 修改的默认值只在当前内容块及其嵌套的子内容块中生效，出了这个范围，默认值会恢复为原来的设置。那什么是“内容块”？继续往下看。

## 参数里的值：基本类型
参数不全是数字，也可以是文字、一段乐谱或对某个音符的引用。函数的每个参数规定好了类型，你需要遵循这些类型的要求。所有类型如下：

| 类型 | 示例 | 用途 | 要求 |
| --- | --- | --- | --- |
| 内容 | `{1 2 3 4}` | 一段乐谱 | 必要时用花括号包裹 |
| 字符串 | `"轻快地"`、`center` | 文字、名称和选项 | 必要时用双引号括起 |
| 布尔值 | `true`、`false` | 开启或关闭某个选项 | 直接写即可 |
| 数字 | `100`、`0.7`、`-12` | 速度、比例和其他数值 | 有限数字范围 |
| 长度 | `12px`、`0.8em` | 字号、间距和页面尺寸 | 必须带单位，默认 `px` |
| 标签 | `start`、`end` | 引用已经标记的对象 | 必须提前标记 |


### 内容块与嵌套
花括号 `{}` 把一段乐谱划为一个内容块，内容块里面可以有任意的乐谱内容。例如给两个音符一起加减时线：

<ScoreExample title="把一段内容交给函数" source="@div({@note(1) @note(2)}, 1)" />

这里的 `{@note(1) @note(2)}` 是第一个参数（类型为内容），`1` 是第二个参数（类型为数值），表示给内容添加一条减时线。

内容在不产生歧义时可以省略花括号，比如上面的例子可以直接这样写：
```text
@div(@note(1) @note(2), 1)
```

那什么时候会有歧义呢？比如内容里出现了逗号：
```text
@div({1, 2}, 1)
```
`{1, 2}` 里面的逗号，是音符函数的简写，表示低八度。如果没有大括号，逗号会被误认为是参数分隔符。

实际上，**整个 jpFun 脚本就是一个巨大的“内容块”**。内容块可以嵌套，比如：

export const nestedContent = `{
  @note(1)
  {
    @note(2)
    @note(3)
  }
}`

<ScoreExample title="嵌套的内容块" source={nestedContent} />

但大括号本身不会在谱面上产生任何视觉效果，去掉之后渲染结果依然不变。但是大括号本身表达了内容的分组与边界，`@set` 函数就是利用了这个作用域来控制设置的作用范围，比如：

export const setScopeExample = `@set(text.size=10px)
@text("文字大小是10px ")
{
  @text("文字大小仍然是10px ")
  @set(text.size=20px)
  @text("文字大小变为20px ")
}
@text("文字大小恢复为10px ")
`

<ScoreExample title="设置作用域示例" source={setScopeExample} />


### 字符串与引号
字符串使用成对的英文双引号 `"`，不能用单引号代替（因为单引号已经用于八度记号）。不会产生歧义时可以省略双引号，因此 `@text(轻快地)` 与 `@text("轻快地")` 效果相同。什么时候有歧义呢？比如文字里有英文逗号时，就应保留引号：
```text
@text("稍快, 有活力")
```

原因和“内容”里一样：逗号是函数参数的分隔符，如果不加括号，直接写会被解析为两个参数：`稍快` 和 `有活力`。

此外，在内容块中的引号还被赋予了特殊的含义——是`@text`的简写，也就是写 `{"文字内容"}` 相当于写 `{@text("文字内容")}`。

### 布尔值/数值/长度
- **布尔值** 即 `true` 或 `false`，用于开启或关闭某个选项。
- **数值** 是普通的数字，必须在有限的数字范围内。
- **长度** 用于表示字号、间距和页面尺寸，例如 `12px`、`0.8em`。可用的单位有 `px` 和 `em`，不写的话默认单位是 `px`。`px` 表示绝对大小，而 `em` 表示尺寸为当前字号的几倍，是一个相对单位。

这三个类型直接写即可，无需担心会被认为是字符串：**解析器知道每个参数的类型，会按照期望的类型去解析**。比如 `@text` 的 `size` 参数期望得到一个长度类型的值，此时你可以直接填写 `16`，解析器会遵循长度类型的解析规则，将其视为 `16px`，而不是数值类型的 16。所以，类型是预先定义好的，而不是加上引号、大括号、单位就能改变的。

### 标签和关系函数
到这里，只要你去阅读函数定义，就可以使用大部分功能了，比如一个附点八分音符：

export const dottedEighthNote = `@dot(
  @div(
    @note(1)
    % 减时线条数默认为1
  )
  % 附点个数默认为1
)`

<ScoreExample title="附点八分音符示例——三层嵌套" source={dottedEighthNote} />

这里嵌套了三层函数调用。然而，嵌套并不能解决音乐排版里的所有问题，比如连音线：创建音符 do re mi，并用连音线连接 do 和 mi —— 你会发现无论怎么设计都无法实现，因为函数只能解决**相邻**音符之间的关系。于是，jpFun 设计了“标签”机制，用于引用之前标记过的对象：

<ScoreExample title="用标签连接两个音符" source="1@start 2 3@end @tie(start, end)" />

`1@start` 给音符 `1` 标上 `start` 的标签，`3@end` 给音符 `3` 标上 `end` 的标签，`@tie(start, end)` 意味着：在标有 `start` 和 `end` 标签的音符之间画一条连音线。

打标签的语法为 **`@标签名`**，有以下规则：
- 后面不能紧跟左括号，否则会被解析为函数调用而不是标签。
- 遇到空格认为标签名结束。一定要勤加空格，不然标签名可能会和后面的内容连在一起。
- 标签绑定到它前面最近的可标注对象，所以中间可以有其他内容——并不是所有元素都可以被打上标签。
- 同一个标签名可以多次被引用和绑定。

export const multipleTagExample = `0@dot(1) -
这里有废话 @start % 依然绑定到前面的do；增时线“-”不可以被打上标签
2 3@end
4@end2  % 这里的 2 并不会被当作音符re，而是作为标签名的一部分
@tie(start, end, end2)  % tie其实可以传递多个标签
`

<ScoreExample title="标签示例" source={multipleTagExample} />

有的时候，标签是可以不打的。就像你在《数鸭子》末尾看到的，`2/ 1/ @tie()` 就没有显式地使用标签。这是因为 `@tie` 的实现非常智能，会自动选择前面的两个音符作为端点。

## 换行转义
最后补充一个不太重要的知识点：换行转义。换行转义的语法是在行末加上反斜杠 `\`，表示当前行与下一行是连续的。例如歌词太长时可以这样写：

export const lineBreakExample = `N: 1234567
L:哆来咪发\
索拉\
踢`

<ScoreExample title="换行转义示例" source={lineBreakExample} />

转义字符 `\` 在字符串、歌词中还有其他用途，比如字符串里要写引号怎么办？可以这样写：
```text
@text("他说：\"你好\"")
```
转义符后面的字符会被视为普通字符，而不会被解析为特殊含义。如果你要在字符串中写反斜杠本身，要用转义字符来转义转义字符：`\\`。

## 总结
- 注释：`%`
- 函数调用：`@函数名(参数1, 参数2=值, ...)`
- 基本类型：
  + 内容，用大括号包裹
  + 布尔值：`true` 或 `false`
  + 数值：普通数字
  + 长度：例如 `12px`、`0.8em`
  + 标签：用于标记和引用对象，需要先用 `@标签名` 给对象打上标签
- 转义：`\`

至此，你已经掌握了 jpFun 的核心了！完整的参数、默认值和别名可随时查阅[函数速查](../../reference/)，不需要一次记住所有函数。之后，我们将通过具体的示例来进一步理解和应用这些知识。
