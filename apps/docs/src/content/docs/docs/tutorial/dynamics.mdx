## 力度符号
力度符号也被收纳在函数 `@symbol` 中，用简写 `$名称` 创建，一般用 `^` 把它放在音符上方。目前支持以下八种力度记号，按从弱到强排列：

| 符号 | 中文术语 | MIDI 播放力度 |
| :--: | :--: | :---: |
| `$ppp` | 极弱 | 16 |
| `$pp` | 很弱 | 32 |
| `$p` | 弱 | 48 |
| `$mp` | 中弱 | 64 |
| `$mf` | 中强 | 80(默认) |
| `$f` | 强 | 96 |
| `$ff` | 很强 | 112 |
| `$fff` | 极强 | 127 |

没有指定力度时，默认播放力度为 `80`，与 `$mf` 相同。

export const dynamicsSymbolsExample = `1^$p 2 3 4 | 5^$f 6 7 1' ||
1^$ppp 2^$pp 3^$p 4^$mp | 5^$mf 6^$f 7^$ff 1'^$fff ||`;

<ScoreExample title="从弱到强" source={dynamicsSymbolsExample} />

第一小节 `1 2 3 4` 都以弱力度播放，从第二小节的 `5` 开始改为强力度。**力度记号从所附着的音符开始生效，并沿当前音轨持续。** 上下摆放只改变谱面位置，不改变力度含义。

## 重音
重音符号用 `@symbol(accent)` 创建，简写为 `$accent`，一般用 `^` 放在音符上方。

**与 `$f` 等持续生效的力度记号不同，`$accent` 只增强所附着音符的力度，不改变后续音符的基础力度。** jpFun 播放时会在该音符原有力度上增加 `20`，最高不超过 `127`。

<ScoreExample title="重音只增强当前音" source="1 ^ $accent ^ $accent   2 ^ $accent _ $mp   3 ^ $mf ^ $accent" />

三个音的力度分别为 `120、84、100`：第一个音叠加两次重音，`80 + 20 + 20 = 120`；第二个音以 `$mp` 为基础，`64 + 20 = 84`；第三个音以 `$mf` 为基础，`80 + 20 = 100`。重音是在当前强弱基础上的强调，并不等于把音符改成固定的强力度。

## 渐强与渐弱
两者使用同一个函数：
```jpfun
@dyn(from, to, dv)
```

- `from`、`to` 是首末音符的标签，范围包含两端，支持跨行。两个标签必须位于**同一音轨、不同记谱时间**。可以跨小节、跨行，但不能连接两个声部，也不能用同一和弦里同时发音的两个音作为首尾。
- `dv` 是数字，表示力度的**变化量**：正数表示渐强，负数表示渐弱。函数会在谱面上方画出相应的楔形记号，并按记谱时间线性改变各个音符的播放力度。

export const dynamicsExample = `% 打标签的时候注意后面加一个空格，不然 ^ 和 _ 会被认为是标签的一部分！
1@start 2/ 3. 4@peak | 5^$f 4@fall 3@end 2^$p ||
@dyn(start, peak, 48)
@dyn(fall, end, -48)\n
1@start ^$p 2/ 3. 4@peak ^$f | 5@fall _$f 4 3 2@end _$p ||
@dyn(start, peak, 48)
@dyn(fall, end, -48)
`;

<ScoreExample title="渐强、渐弱与力度符号的摆放" source={dynamicsExample} />

1. **第一小节展示渐强。** 从默认力度 `80` 开始，四个音符的力度依次为 `80、96、104、127`。音符时值不同，力度按记谱时间变化；终点原本应为 `128`，被限制为 `127`。
2. **第二小节展示两端带力度符号的渐弱。** `$f`、`$p` 放在首尾，渐弱的标签却放在中间两个音上，因此实际力度是 `96、96、48、48`，不是四个音均匀递减。这种写法呈现了渐弱的视觉效果，但播放只在中间两个音之间发生一次力度下降。
3. **第三小节展示把标签放在首尾的效果。** `@dyn` 的避让范围包含端点；首尾音符上方有 `$p`、`$f` 时，楔形记号会被顶到这些符号上方。这也是第二小节把标签放在中间的排版原因。四个音符的力度依次为 `48、64、72、127`。注意，终点的 `$f` 还会**与渐强增量叠加**，按 `96 + 48 = 144` 计算后被限制为 `127`，不能把它当作渐强的目标力度。
4. **第四小节把力度符号放到下方。** 用 `_` 代替 `^`，首尾标签仍覆盖整个小节，上方的楔形记号便不必为了避让上方力度符号而抬高。四个音符的力度依次为 `127、127、112、1`。这里展示的是摆放方式；移动符号不会改变播放规则，也不会消除力度符号与渐变增量的叠加。和 3 同样，这里的演奏力度是有问题的，只是看起来好看。

关于 `@dyn` 和 `@tie` 的重叠问题，请参考 [反复与播放:跳房子与连音线等重叠问题](../repeat/#跳房子与连音线等重叠问题)。
